# OpenClaw Google Calendar

Aplicación de uso personal que conecta OpenClaw con Google Calendar y otros servicios de Google (Gmail, Drive, Docs, Sheets y Slides) para gestionar la cuenta de su propietario.

## Política de privacidad
- La aplicación solo accede a la cuenta de Google autorizada por su propietario.
- No comparte datos con terceros.
- Los tokens de acceso se guardan únicamente en el servidor del propietario.
- El propietario puede revocar el acceso en https://myaccount.google.com/permissions.
